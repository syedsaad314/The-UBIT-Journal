Q1Digital Signal, Circuit Components & Triggering

(a) Digital Signal + Basic Components

Digital signal: a signal that carries information as a sequence of discrete values (usually two levels, 0 and 1), each corresponding to a fixed voltage range, unlike an analog signal which varies continuously.

Basic components of a digital circuit:

  1. Logic Gates (AND, OR, NOT, NAND, NOR, XOR)
  2. Flip-Flops / Latches (memory element, 1 bit)
  3. Registers (group of flip-flops)
  4. Counters (count clock pulses)
  5. Multiplexers / Demultiplexers
  6. Encoders / Decoders
  7. Clock / timing source

(b) Four Clock Triggering Methods

1. Positive Edge Triggering: flip-flop responds only at the 0→1 transition of clock. Symbol: arrowhead, no bubble.

2. Negative Edge Triggering: responds only at the 1→0 transition. Symbol: arrowhead + bubble.

3. Positive Level Triggering: flip-flop stays active/transparent the whole time clock = 1. No arrowhead.

4. Negative Level Triggering: stays active the whole time clock = 0. Bubble, no arrowhead.

Q4Not Confirmed — Quick Backup Notes

Q4 wasn't recalled by the student. Quick-glance backups, most likely of these topics.

JK Flip-Flop: fixes SR's invalid state. J=K=1 → toggles output (Q→Q'). Truth table: 00=Hold, 01=Reset, 10=Set, 11=Toggle.

Half Adder: Sum=A⊕B, Carry=AB. Full Adder: Sum=A⊕B⊕Cin, Carry-out=AB+Cin(A⊕B).

Sync vs Async Counter: Async = ripple, each FF clocked by previous FF's output (delay builds up). Sync = all FFs share same clock (change together, faster).

Code conversion: BCD = 4-bit code per decimal digit. Excess-3 = BCD + 0011. Gray code = adjacent values differ by only 1 bit.

Q6Complex Simplification & Conversions

(a) Simplify + Draw Logic Diagram

F = [(A.B)' + C].D
(A.B)' = A' + B'  (De Morgan)
F = (A' + B' + C).D
F = A'D + B'D + CD  (Distribute D)
Final: F = A'D + B'D + CD

(b) Number System Conversions

1. Decimal→Binary: 156÷2 repeatedly → remainders (bottom-up): 10011100 → 156₁₀ = 10011100₂

2. Binary→Decimal: 11010101₂ = 128+64+16+4+1 = 213₁₀

3. Decimal→Octal: 156÷8 repeatedly → remainders: 4,3,2 → 156₁₀ = 234₈

4. Decimal→Hex: 156÷16 repeatedly → remainders: C,9 → 156₁₀ = 9C₁₆

5. Hex→Binary: 9→1001, C→1100 → 9C₁₆ = 10011100₂
