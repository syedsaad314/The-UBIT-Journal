Digital & Analog Signals

CORE

An Analog Signal is continuous — it can take any value at any point in time. Like a volume knob that smoothly goes from 0 to 100, or a microphone picking up sound waves that rise and fall smoothly. The problem with analog in computers: any tiny electrical noise changes the signal value and causes errors.

A Digital Signal has only TWO states: HIGH (logic 1) and LOW (logic 0). Like a light switch — ON or OFF, nothing in between. All computers work with digital signals because noise cannot easily flip a 0 to 1 since both states are far apart in voltage.

FeatureAnalogDigital
ValuesInfinite, continuousOnly 0 or 1
Noise sensitivityHigh — easily corruptedLow — very reliable
ExampleSound waves, temperatureComputer data, clock signal
Used inMicrophones, thermometersComputers, phones, CPUs

HOT

Boolean Algebra is the mathematics behind logic circuits. These laws let you simplify complex expressions into simpler ones — fewer gates, cheaper circuits.

De Morgan's Theorem — Full Detail ⭐

De Morgan's is perhaps the single most tested theorem in DLD. It tells you how to break a NOT (overbar) that covers multiple variables.

Rule 1: (A · B)̄ = Ā + B̄      Rule 2: (A + B)̄ = Ā · B̄

3-Step Method — "Break, Flip, Bar Each":

  1. Break the main bar (remove it)
  2. Flip the operator (AND · becomes OR +, and OR + becomes AND ·)
  3. Bar each individual variable separately

Example 1: (A + B + C)̄

Break the bar. Flip + to ·. Bar each variable:
→ Ā · B̄ · C̄

Example 2: (Ā · B · C̄)̄

Break the bar. Flip · to +. Bar each (double bars cancel):
→ (Ā)̄ + B̄ + (C̄)̄ = A + B̄ + C
Solved Questions — Boolean Laws
Q4Simplify: Y = AB + A(B + C) + B(B + C)▶
Y = AB + A(B+C) + B(B+C)
  = AB + AB + AC + BB + BC     [Distribute]
  = AB + AB + AC + B + BC      [BB = B, Idempotent]
  = AB + AC + B + BC           [AB+AB = AB, Idempotent]
  = AC + B + BC                [B+AB = B, Absorption]
  = AC + B                     [B+BC = B, Absorption]

Final: Y = B + AC ✓

Exam tip: Name each law used at every step — it shows understanding and earns full marks.

This is exactly what a NAND gate computes!

Y = (A+B)(A+C̄)(B̄+C)

(A+B)(A+C̄) = A + BC̄   [Distributive: A+(BC)=(A+B)(A+C)]

CC̄ = 0 → BC̄C = 0

Karnaugh Maps (K-Map) — 3 & 4 Variable

HOT

A K-Map is a visual method for minimizing Boolean expressions. Instead of using algebra, you place truth table outputs on a grid, group the 1s, and read off the simplified terms. The bigger the group, the simpler the expression.

⚠️ CRITICAL: K-Map uses Gray Code order — NOT normal binary! Columns go: 00 → 01 → 11 → 10. Notice 11 before 10. Using normal binary order is the most common exam mistake.
3-Variable K-Map Layout
4-Variable K-Map Layout
📌 K-Map Grouping Rules:
1. Group only 1s (for SOP minimization) or only 0s (for POS)
2. Group sizes must be powers of 2: 1, 2, 4, 8, 16
3. Groups must be rectangles (squares allowed too)
4. Wrap-around is allowed — left edge connects to right, top connects to bottom
5. Make every group as LARGE as possible
6. Every 1 must be in at least one group
7. Use as FEW groups as possible
8. Don't-Cares (X) can be treated as 1 to form larger groups
✅ How to read a group: If a variable stays SAME (all 0 or all 1) across all cells in the group → include it in the term. If it CHANGES (has both 0 and 1) → eliminate it. Bigger group = more variables eliminated = simpler term.
Solved Questions — K-Map

SOP (Sum of Products) & POS (Product of Sums)

KEY
SOP — Sum of Products

SOP means you write an OR (+) of AND (·) terms. You scan the truth table for rows where F = 1, and write a minterm for each.

Minterm rule (for F=1 rows): If variable = 0 → write with bar (Ā). If variable = 1 → write as-is (A). AND them together.

F = Σm(list of minterm numbers)
POS — Product of Sums

POS means you write an AND (·) of OR (+) terms. You scan the truth table for rows where F = 0, and write a maxterm for each.

Maxterm rule (for F=0 rows) — OPPOSITE of SOP: If variable = 0 → write WITHOUT bar (A). If variable = 1 → write WITH bar (Ā). OR them together.

F = ΠM(list of maxterm numbers)
⚠️ The most common exam mistake: students use the SOP rule for POS. Remember — for maxterms, 0 stays plain and 1 gets the bar. It is the OPPOSITE of minterms.

Sequential Circuits — Latches & Clock Types

KEY

A sequential circuit remembers its previous state. Its output depends on both the current input AND the stored state. The memory element is a flip-flop or latch. Sequential circuits are used in counters, registers, and memory units.

SR Latch (NOR-based) — Most Basic Memory Element

The SR Latch stores 1 bit. S = Set (forces Q=1). R = Reset (forces Q=0). It is built using two NOR gates cross-coupled in a feedback loop. It is level-triggered — responds whenever inputs change, with no clock.

SRQ (next)State
00Q (no change)Hold
010Reset
101Set
11?INVALID!
Red dashed = cross-coupled feedback paths
⚠️ S=1, R=1 is the FORBIDDEN state. Both NOR outputs are forced to 0 simultaneously, violating Q ≠ Q̄. The circuit becomes unpredictable.

Flip-Flops — SR, JK, D, T

HOT — Full question certain

A flip-flop is an edge-triggered memory element. It stores exactly 1 bit and only updates at the clock edge (rising or falling). All modern digital systems use flip-flops as their basic storage unit — registers, counters, and memory all rely on them.

SR Flip-Flop

The clocked version of the SR latch. S = Set (Q→1). R = Reset (Q→0). The forbidden state S=R=1 still exists.

The JK flip-flop fixes the forbidden state of SR. When J=K=1, instead of being invalid, the output toggles (flips to opposite). J behaves like S (set), K behaves like R (reset). No forbidden state exists.

SR Flip-Flop — Definition and Problem

The SR flip-flop is the basic clocked memory element. S stands for Set (makes Q=1) and R stands for Reset (makes Q=0). When S=0 and R=0, the output holds its previous state. When S=0, R=1, output resets to 0. When S=1, R=0, output sets to 1.

However, the SR flip-flop has one critical flaw: the state S=1, R=1 is forbidden/invalid. When both S and R are 1 simultaneously, both Set and Reset are active at the same time and the circuit cannot decide which should win. Both Q and Q̄ are forced to 0, which violates the fundamental rule that Q and Q̄ must always be complements of each other. The output becomes unpredictable.

JK Flip-Flop — Solution

The JK flip-flop solves this completely. J works like S (sets Q to 1) and K works like R (resets Q to 0). For J=0,K=0 and for J=0,K=1 and J=1,K=0 — the behavior is identical to SR.

The key difference is J=K=1: instead of being invalid, the JK flip-flop is designed so that J=K=1 causes the output to toggle — Q flips to its complement. If Q was 0, it becomes 1. If Q was 1, it becomes 0. This is well-defined, predictable behavior.

Why JK is preferred

The JK flip-flop is preferred because: (1) No forbidden state exists. (2) It can be configured as an SR FF (use J as S, K as R, avoid both=1). (3) By connecting J=K=T, it becomes a T flip-flop. (4) By connecting K=J̄, it becomes a D flip-flop. This makes JK the most versatile flip-flop — it can replace all others.

Characteristic equations: SR: Q(next) = S + R̄·Q (with SR=0 constraint). JK: Q(next) = J·Q̄ + K̄·Q (no constraint needed).

Q12Draw the timing diagram for a D flip-flop (rising edge) with D = 1,0,1,1,0 over 5 clock cycles. Initial Q=0.▶
Clock edge 1 (↑): D=1 → Q becomes 1
Clock edge 2 (↑): D=0 → Q becomes 0
Clock edge 3 (↑): D=1 → Q becomes 1
Clock edge 4 (↑): D=1 → Q stays 1
Clock edge 5 (↑): D=0 → Q becomes 0

Rule: Q(next) = D — D Flip-Flop simply stores whatever D is at the clock edge.

Counters & Registers

THEORY
Counters

A counter is a sequential circuit that counts clock pulses. Each time the clock ticks, the counter moves to the next state. Built using T or JK flip-flops.

TypeHow it worksSpeed
Asynchronous (Ripple)Each FF is triggered by the Q output of the previous one. The clock "ripples" through.Slower — delay accumulates
SynchronousALL flip-flops triggered by the same clock simultaneously.Faster — no accumulated delay
Up CounterCounts upward: 0, 1, 2, 3, 4 ...—
Down CounterCounts downward: 7, 6, 5, 4 ...—
Mod-N CounterCounts from 0 to N−1 then resets. Mod-6 counts 0,1,2,3,4,5,0,1...—
📌 An n-bit counter has 2ⁿ states. 2-bit → 4 states (0–3). 3-bit → 8 states (0–7). 4-bit → 16 states (0–15).
Registers — Types and Uses

A register is a group of flip-flops (usually D flip-flops) used to store multiple bits. An n-bit register stores n bits. Registers are used inside CPUs for temporary data storage during computation.

TypeInputOutputDescription & Use
SISOSerial (1 bit/clock)Serial (1 bit/clock)Data shifts one bit at a time. Slowest. Used as delay element.
SIPOSerial (1 bit/clock)Parallel (all at once)Enter bits one by one, read all at once. Used in serial-to-parallel conversion.
PISOParallel (all at once)Serial (1 bit/clock)Load all bits at once, shift out one by one. Used in parallel-to-serial conversion.
PIPOParallel (all at once)Parallel (all at once)Fastest. All bits in and out simultaneously. Used for temporary storage in CPUs.
Universal ShiftBoth modesBoth modesCan do all 4 modes. Controlled by mode select lines. Most flexible.
✅ Exam tips: SIPO = serial-to-parallel converter. PISO = parallel-to-serial converter. PIPO = fastest (used in CPU registers). SISO = slowest (used as delay). Universal = most flexible (all modes).
